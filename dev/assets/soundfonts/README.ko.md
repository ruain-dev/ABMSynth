# FluidR3

동봉 음원은 Frank Wen의 FluidR3 GM 3.1입니다.
Debian 원본 배포의 `FluidR3_GM.sf2`를 `FluidR3.sf2`로 이름만 바꿨습니다.
파일 내용은 동일합니다. 148,398,306 bytes이며 SHA-256은 아래와 같습니다.

```text
74594e8f4250680adf590507a306655a299935343583256f3b722c48a1bc1cb0
```

MIT 사용 조건과 제작자의 안내는 앱의 ‘라이선스 및 저작권’ 창에서
FluidR3를 선택하면 확인할 수 있습니다.
ABMSynth 자체 코드의 사용 조건은 이 음원의 권리를 제한하지 않습니다.
