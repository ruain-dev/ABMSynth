# 조율 기준음

`tuning-reference.sf2`는 ABMSynth가 생성한 사인파 음원입니다.
외부 녹음이나 다른 SoundFont의 샘플을 포함하지 않습니다.
사용 조건은 저장소 루트의 LICENSE와 ADDITIONAL_PERMISSIONS.md를 따릅니다.

44,100 Hz 모노 샘플은 110주기를 포함하고 1초 구간을 반복합니다.
기준 건반은 A2이며 A4에서 440 Hz를 냅니다.
음량 윤곽은 Attack 5 ms, Sustain 100%, Release 25 ms입니다.
