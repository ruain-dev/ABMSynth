# 번역 카탈로그

`ko-KR.json`은 한국어 화면 문구이고 `template.json`은 번역용 키 목록입니다.
`i18n.py`가 문구와 대체값을 읽습니다.

- 키 이름과 `{name}` 형태의 대체값 이름은 유지합니다.
- 버튼은 동작을, 툴팁은 조절 결과와 중요한 조건을 설명합니다.
- MIDI의 개별 음은 ‘노트’, 강도 조절은 `Velocity`로 표기합니다.
- 숫자 선택은 `Program`, 악기명 선택은 `Instrument`를 사용합니다.
- `Reset`, `Panic`, ‘기본값 복원’은 서로 다른 동작입니다.
- 측정할 수 없는 값은 `—`, 음의 무한대는 `−∞`입니다.
- 음이름, 코드 기호, MIDI 단위와 공식 효과 이름은 번역하지 않습니다.
